# ICHA 2026 Status Flow

## Registration
PENDING → WAITING_VERIFICATION → PAID
WAITING_VERIFICATION → REJECTED

## Abstract
DRAFT → SUBMITTED → UNDER_REVIEW
- ACCEPTED
- REJECTED
- REVISION_REQUIRED → RESUBMITTED → ACCEPTED

`UNDER_REVIEW` is internal admin checking only.

## Full Paper
SUBMITTED → APPROVED
SUBMITTED → REVISION_REQUIRED → SUBMITTED

## Conference Journey
ACCOUNT → PROFILE → REGISTRATION → PAYMENT → ABSTRACT → ADMIN CHECK → ACCEPTED → FULL PAPER → PRESENTATION → CONFERENCE → CERTIFICATE → PUBLICATION

## No Reviewer
There is no external reviewer workflow.
